鉱脈の裏切り者 v18 オンライン起動手順

必要なもの
- Node.js 20以上
- インターネット接続（最初の npm install のみ）

Windowsでの起動
1. このフォルダを展開します。
2. start_online_windows.bat をダブルクリックします。
3. 初回は依存パッケージのインストールが走ります。
4. ブラウザで http://localhost:3000 を開きます。
5. ゲーム上部の「オンライン」から名前を設定し、部屋を作成または参加します。

手動起動
1. ターミナルでこのフォルダを開きます。
2. npm install
3. npm start
4. http://localhost:3000 を開きます。

外部公開
- Render、Railway、Fly.io等へこのフォルダをデプロイできます。
- PORT環境変数に対応しています。
- ratings.json に名前ごとのレートを保存します。

実装済み
- オンラインボタン
- プレイヤーネーム
- 6文字ルームコード
- 2～8人ロビー
- ルームチャット
- レートの永続保存と対戦後更新
- ホスト進行によるオンライン対戦開始

現時点の制限
- 盤面・手札・秘密役職を各参加者へ安全に分ける完全同期は未完成です。
- 現在はホスト端末がゲーム進行を担当するオンラインβです。
- 本番の完全同期には、ゲーム状態をサーバー側へ移し、各プレイヤー専用の非公開情報だけを配信する設計が必要です。


v18の秘密情報設計
- ゴール調査結果はプレイヤーごとの goalKnowledge に分離しました。
- 現在のホスト進行βではホスト端末内で管理されます。
- 完全同期版へ進める際は、サーバーが各プレイヤー本人にだけ
  goalKnowledgeを送信する必要があります。


v18の手番同期要件
- サーバー同期版では turnActionTaken をサーバー側で管理してください。
- クライアントから手番終了要求が来た場合、カード使用・廃棄・交換の履歴が
  1件以上あることをサーバー側でも検証する必要があります。


v18の非公開職業情報
- professionKnowledgeはプレイヤーごとの非公開情報です。
- 完全同期版では、本人のprofessionKnowledgeだけを本人へ送信してください。
- 職業交換後に全員へ職業情報をブロードキャストしてはいけません。

v18のAI設定
- 現在のホスト進行βでは、ホストが選択したAI難易度が使用されます。
- 完全同期版では、ルーム設定としてaiDifficultyをサーバー側に保持してください。


v18の非公開情報
- ゴール調査では保管品を移動しません。
- 保管品の移動は、サーバーが道の到達を確定した時だけ行ってください。
- professionKnowledgeとgoalKnowledgeは本人にだけ送信してください。
- 手札交換では、交換相手以外へカード内容を送信してはいけません。


v18
- ランダム選択はホスト端末が開始時に抽選します。
- 完全同期版では確定したstageKeyを全参加者へ送信してください。


v18の報酬同期
- 勝利報酬プールと山分け計算は、完全同期版ではサーバー側で確定してください。
- campaignDataは現在クライアントのブラウザ内へ保存されます。
- オンラインアカウント間で累計を共有する場合は、サーバーのプロフィールDBへ
  累計報酬を保存する処理が別途必要です。


v18の追加同期項目
- pathUseCount と pathLimit をサーバー側で管理してください。
- 坑道ラッシュ使用後は、同じ手番で道カードを合計3枚まで許可します。
- sabotageMarks、sabotageBonus、geologistBonus、crystalsもゲーム状態へ含めてください。
- 手札と山札がともに0のプレイヤーは、サーバー側で自動スキップしてください。


v18 オンラインNPC
- ホストが追加NPC数とNPC難易度を設定します。
- 設定はroom_stateで全参加者へ同期されます。
- 人間とNPCの合計上限は8人です。
- start_match時にnpcCountとaiDifficultyが全員へ送られます。
- 対戦結果によるレート更新は接続中の人間だけに行われます。

v18 秘匿関係AI
- grudgesとfavorsはNPC内部の判断値です。
- 完全同期版でも、これらの値はクライアントへ送らず、
  サーバー側だけで管理することを推奨します。


v18 開始演出
- ホスト進行βでは、対戦開始時に確定したステージ紹介を表示します。
- 完全同期版では、確定ステージを全参加者へ送信し、
  各端末でステージ紹介後に本人の役職画面を表示してください。


v18のチャット
- ホスト進行中のNPC会話はホスト端末のルールベース処理で生成されます。
- 外部AI APIは使用しません。
- 完全同期版ではNPC発言をサーバーイベントとして全員へ配信してください。
- NPCのbehaviorBeliefs、grudges、favorsは秘密の内部値として、
  クライアントへ公開せずサーバー側に保持することを推奨します。

v18のゲームボリューム
- 完全同期版では volumeKey、exactDeck、moreChaos をルーム設定に含めてください。


v18 冷酷CPU
- _profitPlanはNPCの非公開一時判断です。
- 完全同期版では、即時勝利道の検証と報酬期待値計算をサーバー側で行ってください。
- 味方排除の理由や評価値はクライアントへ送らず、実行された公開行動だけを配信してください。


v18 変動ステージ同期
- 通常カジノは2巡ごとに1列を1マスだけ動かします。
- 時計仕掛け、奈落レール、亡霊坑道は3巡ごとです。
- 完全同期版では、移動対象、方向、ゴール交換対象をサーバー側で抽選し、
  全端末へ同じ結果を送信してください。


v18 デプロイ補助
- render.yaml と Dockerfile を同梱しています。
- GitHubへpushした後、RenderまたはRailwayのNode.js Web Serviceとして公開できます。
- GitHub Pagesは静的配信専用なので、Socket.IOサーバーの公開先には使用できません。
- 現行版の盤面対戦はホスト進行βです。
- 完全同期へ移行する手順はONLINE_FULL_SYNC_PLAN.mdを参照してください。

v18 秘密情報の注意
- 完全同期版では、手札、職業、個人のゴール知識、職業知識、
  NPC内部推測を全員へbroadcastしてはいけません。


v18 使用可能性の検証
- 完全同期版では、カード使用要求を受けたサーバーが itemUsed、pathUseCount、デバフ、対象妥当性を再検証してください。
- クライアントのボタン無効化だけを信用してはいけません。
